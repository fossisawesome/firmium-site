# Contributing to firmium-site

Thanks for your interest in improving the Firmium showcase site.

## Getting Started

```bash
npm install
npm run dev
```

The site is built with Vite + Svelte + TypeScript.

## Making Changes

- Component/UI changes: edit the Svelte components under `src/`.
- Run `npm run check` (svelte-check + tsc) and `npm run build` before submitting to make sure the site type-checks and builds cleanly.

## Copy Guidelines

- Don't repeat the same feature, word, or phrase across sections/cards — each feature belongs in one place, wherever it's most relevant.
- Before adding new copy, check existing sections for overlap.

## Submitting Changes

1. Fork the repository and create a branch for your change.
2. Make your changes and verify the site builds (`npm run build`).
3. Open a pull request describing what changed and why.

## Reporting Issues

Open an issue describing the problem, including steps to reproduce if applicable.
